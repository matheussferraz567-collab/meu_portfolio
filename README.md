# Projetos
Titanic Analytics
Análise Exploratória de Dados e Business Intelligence · Ferramentas: Excel e Power BI

Análise do conjunto de dados do Titanic para investigar o perfil dos passageiros e identificar padrões relacionados às taxas de sobrevivência. O trabalho envolveu tratamento e organização dos dados, análise exploratória, construção de indicadores e um dashboard interativo no Power BI, considerando idade, sexo, classe do passageiro e local de embarque.
